A single-sentence entry for the make.fun competition "Everyday Wonder, Two Days to Find the Line": a vending machine hands over two chocolate bars for the price of one.

`main.py` (Python stdlib only) writes a single original line to
`entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

The line:

## Run it
